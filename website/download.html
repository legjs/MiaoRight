下载后怎么用

首次安装按下面的顺序操作。遇到「无法验证开发者」或「Apple 无法检查是否包含恶意软件」时，请看第 2 步。

以下配图均为操作示意，系统名称和按钮位置会随 macOS 版本略有变化。

  1. 解压，放进「应用程序」

    在访达打开「下载」，双击刚下载的 ZIP。将解压得到的 MiaoRight.app 拖到访达边栏的「应用程序」，然后从「应用程序」里双击打开。

    如果已有旧版，先从妙右菜单退出，再用新版替换。请先完成解压，再移动 App。

  2. 被 macOS 拦截时，允许这一次打开

    当前版本尚未经过 Apple 公证。请确认安装包来自本页的 GitHub 发行链接，再继续。如果能正常打开，直接进入第 3 步。

    先尝试打开一次妙右，关闭拦截提示。打开苹果菜单中的「系统设置」，进入「隐私与安全性」，向下滚动至「安全性」，找到关于妙右的拦截记录，点「仍要打开」。按系统提示输入 Mac 登录密码或使用触控 ID，再在确认提示中点「打开」。

    找不到「仍要打开」怎么办？

    回到「应用程序」，再双击一次妙右，再返回「隐私与安全性」的「安全性」区域。也可以用系统设置的搜索框搜索「安全性」。公司或学校管理的 Mac 可能限制此项操作，需要联系管理员。

    提示「已损坏」「将损坏你的电脑」，或仍然打不开

    如果提示 App 已损坏，先重新下载并解压。核对 ZIP 的 SHA-256 和发行页的校验文件，检查下载是否完整。若提示「将损坏你的电脑」或包含恶意软件，请停止安装，并向项目反馈完整提示。

    只在确认来源、ZIP 校验值一致，且没有恶意软件警告的情况下，才继续排查下载隔离标记。展开下面的说明。

    校验文件和处理下载隔离标记

    同时下载本页的 ZIP 和 SHA256SUMS，在「文本编辑」中打开 SHA256SUMS。打开「应用程序 → 实用工具 → 终端」，运行下面的命令，将输出与相同 ZIP 文件名对应的校验值逐字对照。

    cd ~/Downloads
shasum -a 256 MiaoRight-v0.1.1-*.zip

    将 App 放入「应用程序」后，运行签名校验。终端没有输出并回到输入提示符时，表示这项校验成功。出现校验错误时，请重新下载，或向项目反馈。

    codesign --verify --deep --strict "/Applications/MiaoRight.app"

    两项校验都通过后，可用下面的命令移除这一份妙右 App的下载隔离标记，再尝试打开。此操作会让该副本跳过相应的下载隔离检查，请仅对你确认信任的副本使用。

    xattr -dr com.apple.quarantine "/Applications/MiaoRight.app"
open "/Applications/MiaoRight.app"

    如果命令提示权限不足或操作不允许，请到项目问题页面反馈系统版本和完整提示。

  3. 启用访达右键和压缩包预览

    打开妙右后，在「通用」页或扩展未启用的提示中点「打开系统设置」。在较新 macOS 上，前往「通用 → 登录项与扩展」，找到下方「扩展」区域。

    在「访达」里启用妙右；在「快速查看」（Quick Look）里启用妙右压缩包预览。如分组右侧有信息按钮 ⓘ，先点它再打开对应开关。macOS 14 可在系统设置中搜索「扩展」，按「访达」和「快速查看」分类查找。

    回到访达，选中文件并右键，检查妙右菜单。查看压缩包内容时，在访达选中 ZIP，使用访达的系统预览。右侧预览面板可通过菜单「显示 → 显示预览」打开，也可按 ⇧⌘P 显示或隐藏。如果扩展尚未出现，先退出再打开妙右；仍未出现时，可从妙右的「通用」页重启访达，再试一次。

  4. 开启剪贴板，允许直接粘贴

    进入妙右的「剪贴板」页，开启「记录剪贴板历史」。复制一段文字，按 ⇧⌘V，新记录就会出现在面板里。

    想选中后直接贴入其他 App，点页面里的「去授权」，进入「隐私与安全性 → 辅助功能」，打开妙右开关。列表中没有时，点「＋」并选择「应用程序」里的 MiaoRight.app。系统要求时用 Mac 登录密码或触控 ID 确认。

    授权后回到想输入文字的 App，点进输入框，再按 ⇧⌘V 选一条记录试贴。也可以在面板里先复制，再按 ⌘V。需要粘贴倒数第二条时，默认快捷键是 ⌃⇧⌘V。

现在可以试一试

右键复制一条文件路径，按 ⇧⌘V 找回它，再在访达中选中一个 ZIP 查看包内目录。剪贴板记录里的「… → 保存…」还能把文字、图片和文件保存到你选的位置。
