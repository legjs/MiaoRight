安装只需三步

下载、拖进去、打开。

妙右是菜单栏工具。第一次安装后，还需要打开几个系统开关，右键菜单和剪贴板才会生效。

自动识别芯片并下载功能没生效

选择正确的版本

打开苹果菜单 →「关于本机」。显示“芯片：Apple M…”选 Apple 芯片；显示“处理器：Intel…”选 Intel 芯片。

下载页会自动推荐当前 Mac 的版本。优先下载 DMG；如果当前版本只有 ZIP，解压后得到 MiaoRight.app。

拖进“应用程序”

双击 DMG，把 MiaoRight.app 拖到 Applications / 应用程序，然后推出 DMG。

之后始终从“应用程序”打开妙右。右键菜单需要它位于 /Applications/MiaoRight.app。

打开妙右，完成三项开关

打开妙右后，在「通用」页会显示“开始使用妙右”，缺哪项就点哪项。

✓Finder 右键菜单
系统设置 → 通用 → 登录项与扩展 → 扩展 → 访达。
✓剪贴板历史
在妙右「剪贴板」页开启，然后按 ⇧⌘V 测试。
✓直接粘贴（可选）
系统设置 → 隐私与安全性 → 辅助功能。未开启时仍可复制后按 ⌘V。
首次被 macOS 拦截
先尝试打开妙右。若提示“无法验证开发者”，到「系统设置 → 隐私与安全性」点“仍要打开”，再确认一次。
安装后还是没有右键菜单或剪贴板

先确认 App 在“应用程序”里，并退出后重新打开。然后在妙右「通用」页查看“开始使用妙右”卡片；仍显示未完成的，就点击右侧按钮。

重启访达后，右键菜单通常会重新加载：

killall Finder

如果是 Intel Mac，安装包必须是 x86_64。高级检查可运行：

uname -m
lipo -archs /Applications/MiaoRight.app/Contents/MacOS/MiaoRight

两行都应显示 x86_64。显示 arm64 说明下载了 Apple 芯片版本。
