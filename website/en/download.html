After downloading ↓

Installers are hosted on GitHub Releases. No account needed.

This build is signed with the project's stable self-signed certificate and is not notarized by Apple. If macOS blocks the first launch, follow the opening guide.Download SHA-256 checksums

To update, quit MiaoRight and replace /Applications/MiaoRight.app. In-app updates from the production-signed build replace that path in place; running a new copy from Downloads will not overwrite a production install.

Install and first-time setup

Follow these steps for a first install. If macOS says the developer cannot be verified, or that it cannot check for malicious software, see step 2.

The illustrations are diagrams. System names and button positions vary slightly by macOS version.

1 Open the DMG and install 2 Allow the first launch 3 Enable extensions 4 Enable the clipboard

  1. Open the DMG and move it to Applications

    Open Downloads in Finder and double-click the DMG you downloaded. Drag MiaoRight.app to Applications in the Finder sidebar, then open it from Applications. If you downloaded the ZIP, unzip it first.

    If you already have an older version, quit it from the MiaoRight menu first, then replace it.

  2. Allow the first launch

    This build is not notarized. Confirm the download came from the GitHub release linked on this page before continuing. If it opens normally, skip to step 3.

    Try opening MiaoRight once and dismiss the warning. Open System Settings, go to Privacy & Security, scroll to Security, find the blocked MiaoRight entry, and click Open Anyway. Enter your Mac password or use Touch ID, then click Open in the confirmation.

    Can't find Open Anyway?

    Return to Applications and double-click MiaoRight once more, then go back to the Security section of Privacy & Security. You can also search System Settings for Security. Macs managed by a company or school may restrict this step; contact your administrator.

    “Damaged”, “will damage your computer”, or it still won't open

    If macOS says the app is damaged, download and unzip it again. Compare the ZIP's SHA-256 with the checksum file on the release page to confirm the download is complete. If macOS says the app will damage your computer or contains malicious software, stop and report the full message to the project.

    Only if you trust the source, the ZIP checksum matches, and there is no malware warning, continue with the download quarantine note below.

    Verify the download and remove the quarantine flag

    Download the ZIP and SHA256SUMS, open SHA256SUMS in TextEdit, open Terminal from Applications → Utilities, and compare the command output with the line for the same ZIP filename.

    cd ~/Downloads
shasum -a 256 MiaoRight-v0.1.3-*.zip

    After moving the app to Applications, verify its signature. If Terminal returns to the prompt with no output, the check passed. If it reports an error, download again or report it to the project.

    codesign --verify --deep --strict "/Applications/MiaoRight.app"

    If both checks pass, you can remove the download quarantine flag from this copy of MiaoRight with the command below, then try opening it again. This bypasses the download quarantine check for that copy; use it only for a copy you trust.

    xattr -dr com.apple.quarantine "/Applications/MiaoRight.app"
open "/Applications/MiaoRight.app"

    If the command reports a permission error or is not allowed, report your macOS version and the full message on the project issue page.

  3. Enable Finder and Quick Look

    Open MiaoRight, then click Open System Settings in the General page or the extension warning. On recent macOS versions, go to General → Login Items & Extensions and find the Extensions section.

    Turn on MiaoRight under Finder, and MiaoRight Archive Preview under Quick Look. If a group has an ⓘ button, open it before turning on the switch. On macOS 14, search System Settings for Extensions and look under Finder and Quick Look.

    Back in Finder, select a file and right-click to check the MiaoRight menu. To preview an archive, select a ZIP and use Quick Look. You can open the preview pane from View → Show Preview, or press ⇧⌘P to show or hide it. If the extension does not appear, quit and reopen MiaoRight. If it still does not appear, restart Finder from MiaoRight's General page and try again.

  4. Enable the clipboard and direct paste

    Open the Clipboard page in MiaoRight and turn on Record Clipboard History. Copy some text and press ⇧⌘V; the new item appears in the panel.

    To paste directly into another app, click Grant Access, then go to Privacy & Security → Accessibility and turn on MiaoRight. If it is not listed, click + and choose MiaoRight.app from Applications. Confirm with your Mac password or Touch ID.

    Return to the app where you want to type, click the field, and press ⇧⌘V to paste a history item. You can also copy an item in the panel and press ⌘V. To paste the second-to-last item, the default shortcut is ⌃⇧⌘V.

Try it now

Copy a file path from the context menu, press ⇧⌘V to find it, then select a ZIP in Finder to see its contents. The … → Save… menu in clipboard history can save text, images, and files wherever you choose.
