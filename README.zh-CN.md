# 妙右 MiaoRight

[English](README.md) · 简体中文 · [官网](https://legjs.github.io/MiaoRight/)

妙右是轻量的 Finder 与剪贴板工具，支持 Apple 芯片和 Intel 芯片的 Mac，最低版本为 macOS 14。在 Finder 里右键打开、移动和整理文件，也可以从剪贴板面板找回、粘贴或保存之前复制的内容。

妙右使用 SwiftUI 和 AppKit，配有原生 Finder Sync 与 Quick Look 扩展。界面支持简体中文和英文，可以跟随系统语言。外观可跟随系统，也可选择浅色或深色。

## 构建与开始使用

在项目目录使用带有 Swift 6.3 的 Xcode Command Line Tools 构建和启动。

```bash
./scripts/build-app.sh release
open build/MiaoRight.app
```

日常测试最快的方式是运行 `./scripts/dev.sh release`。脚本会先正常退出正在运行的妙右，再重新构建 Release 包，更新 `/Applications/MiaoRight.app` 中的开发签名测试包，重新注册 Finder Sync 扩展并启动。macOS 26 下从构建目录启动时，系统可能只登记扩展而不实际加载进程。

脚本会构建并签名主程序、Finder Sync 与 Quick Look 扩展，以及内置的 7-Zip 工具。它优先使用本机的 `MiaoRight dev` 签名身份，找不到时回退到 ad-hoc 签名。请通过 `open` 启动，让 LaunchServices 注册扩展。证书配置见[开发签名指南](MACOS_DEV_SIGNING.md)。

本地构建默认使用当前 Mac 的架构。发行版中，Apple 芯片请选择 `arm64` DMG，Intel 芯片请选择 `x86_64` DMG；ZIP 保留给应用内更新。GitHub Actions 会用长期有效的 `MiaoRight Release` 身份签名两种架构，并附上 SHA-256 校验文件。发布工作流从 Actions Secrets 导入签名身份，缺少证书时会停止发布，不会退回 ad-hoc 包。 [发布流程](docs/GitHub-更新发布.md)

- **Finder 右键。** 在系统设置的「登录项与扩展 → Finder 扩展」中启用妙右。扩展未启用时，妙右主窗口会显示「打开系统设置」按钮。
- **剪贴板历史。** 首次使用时，开启「剪贴板 → 记录剪贴板历史」，复制一条内容后按 `⇧⌘V` 呼出面板。
- **偏好设置。** 主窗口有「右键菜单」「剪贴板」「保险箱」「通用」四个页面。在「通用」里可设置语言、外观、Finder 菜单生效范围与「登录时启动」。

## 剪贴板历史

| 操作 | 怎么用 |
| --- | --- |
| 找回一条记录 | 按 `⇧⌘V` 打开面板。可以搜复制过的文字、列表上显示的文件名，也可以输入截图里出现过的词。妙右会在本机识别已记录图片中的文字。 |
| 保存一条记录 | 点任意记录的「… → 保存…」。文字和链接存为 UTF-8 编码的 TXT，图片存为 PNG，文件和文件夹复制到你选的目录。复制时需要能访问原文件，遇到同名文件会另取编号。 |
| 粘贴倒数第二条 | 默认按 `⌃⇧⌘V`。例如先复制标题，再复制链接，按这个快捷键贴标题，接着按 `⌘V` 贴链接。两个全局快捷键均可在剪贴板设置里修改。 |
| 留住常用内容 | 在记录菜单里收藏，或在剪贴板设置里保存常用文字。到期清理、条数上限和「清除未收藏历史」都不会清除收藏。 |

面板支持键盘定位、数字快选、多选、筛选和固定。直接粘贴和粘贴倒数第二条需要辅助功能权限。也可以在面板中复制所选项，再自己按 `⌘V`。

历史只保存在本机。剪贴板设置里可以暂停记录、更改保留时间和调整条数上限。收起面板后，已经开启的记录仍会继续。当前每条文字最多记录 10,000 个字符，超过 5 MB 的图片会跳过。

## Finder 右键操作

- **复制文件路径**复制所选文件或文件夹的完整路径。
- **用应用打开**使用你在「右键菜单」里选好的本机应用，也支持拖入应用。**在终端打开**使用已安装的终端。选中文件时会打开它所在的目录。
- **剪切**标记待移动的文件。到目标文件夹后选**粘贴到此处**。移动失败时，未完成的项目会保留，方便重试。
- **常用文件夹**可分别启用打开、复制到和移动到。**文件模板**保存一份快照，便于在目标文件夹里新建模板副本。
- 在「右键菜单 → 添加功能」中按需启用「批量重命名…」、图片转换、PDF 处理和校验等工具。批量重命名会预览新名称并检查冲突。

文件操作完成后，可从结果区在 Finder 定位产物。当前 App 会话内，符合条件的移动和重命名可以撤销，前提是原位置可用且文件仍与记录的状态一致。

## 压缩包

- **在访达预览目录。** 在访达选中压缩包后按空格，或使用「显示 → 显示预览」（⇧⌘P）。妙右的只读 Quick Look 预览扩展会在系统的快速预览中显示目录树、大小、可用的修改时间和统计。妙右 App 内没有压缩包预览入口或专用快捷键。支持 ZIP、7Z、RAR、TAR、常见 TAR 压缩格式、GZ、BZ2、XZ 和 CPIO。大型或加密压缩包可能只显示部分内容或无法显示目录；加密目录可用「解压」输入密码。若由其他应用接管预览，可在系统设置中检查 Quick Look 扩展。
- **创建压缩包。** 在「右键菜单 → 添加功能 → 压缩与解压」启用「压缩…」，可选 ZIP、7Z 或 TAR.GZ。ZIP 与 7Z 支持加密，密码含中文等非 ASCII 字符时请选择 7Z。
- **解压文件。** 在同一分组启用「解压」。支持 ZIP、7Z、RAR、TAR、GZ、BZ2、XZ、TAR 压缩格式与常见分卷。将各分卷放在同一目录，选中首个分卷操作。内容解压到压缩包旁的新文件夹。如果加密目录无法预览，可用这个入口输入密码并解压。

压缩和解压使用与 App 架构匹配的内置 7-Zip，密码只在当次操作中使用。Quick Look 扩展使用系统 libarchive 读取目录信息。 [内置 7-Zip](ThirdParty/7zip/README.md)

## 加密保险箱

在「保险箱」页创建本地 AES-256 加密磁盘镜像后，可在同页加入文件，也可以在「右键菜单 → 添加功能」启用「加入保险箱」，再从 Finder 右键移入。加入保险箱会移动原件，「取出…」则复制一份到所选位置。

Mac 睡眠、退出妙右或达到设定的空闲时间时，保险箱会锁定，空闲时间默认是 15 分钟。可以选择把密码存到登录钥匙串。请妥善保管密码，恢复保险箱内容需要它。

## 开发与验证

- 运行 XCTest 需要完整 Xcode。参见[离屏测试设置](AGENTS.md)、[产品说明](PRODUCT.md)和[设计系统](DESIGN.md)。
- 版本历史遵循 Keep a Changelog 与语义化版本，见 [CHANGELOG.zh-CN.md](CHANGELOG.zh-CN.md)；英文版为 [CHANGELOG.md](CHANGELOG.md)。
- 「通用 → 软件更新」默认每天检查一次公开的稳定发行版，也可以随时手动检查，自动检查可关闭。发现新版本后会跨启动保留提示。妙右位于 `/Applications/MiaoRight.app` 时，可直接下载匹配的 ZIP，校验 Bundle ID、发行版本、架构、嵌套扩展和固定发布证书后退出、原位替换并重新启动。具体配置见[更新检查说明](docs/GitHub-更新发布.md)。
- 最新功能验证通过了 Release 构建、深度签名校验，以及 58 项剪贴板、压缩包和菜单相关的离屏测试。测试范围未覆盖前台保存对话框、Finder 与 Quick Look 完整交互、VoiceOver 及物理多屏。[早期执行记录](docs/日常功能补齐-执行记录.md)保留了之前各轮的验证结果。
