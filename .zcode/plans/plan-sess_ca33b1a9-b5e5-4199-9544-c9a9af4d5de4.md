# 妙右 UI 重设计方案

## 设计概念:「玻璃流光」

这份早期方案以浅色渐变和半透明卡片组织内容，计划采用首页、搜索与紧凑列表承载原有功能。交互在主窗口内完成。当前设计见 [DESIGN.md](../../DESIGN.md)。

## 一、设计系统基建(新建 `Sources/MiaoRightKit/Theme/`)

- **MiaoTheme.swift**：浅色使用低饱和的 teal、indigo、pink 线性渐变，深色降低亮度。场景颜色统一由 `BuiltInMenuCategory.colorHex` 提供，主题另设统一的强调色。
- **MiaoComponents.swift**:`GlassCard`(材质卡+细描边)、`SectionHeader`、`StatusPill`(三态状态胶囊)、`EmptyStateView`、`SearchField`(⌘K 聚焦)、`MiaoButtonStyle`(渐变胶囊主按钮/玻璃次按钮)、`ActionRow`(紧凑动作行)
- 最低版本为 macOS 14。

## 二、信息架构(ContentView 重构)

侧栏从 9 项瘦身为 5 项,场景由侧栏条目变为页内筛选:

```
▣ 首页(默认)  ─────────  ▤ 动作库  ⛓ 工作流  🧩 扩展  ⚙ 设置
```

**首页(新 HomeView)**:顶部大搜索框(输入即筛选全部内置+自定义动作和工作流,行内结果可直接开关)→ 「常用」动作 chips(点击跳动作库并预填搜索)→ 5 张场景入口卡(显示 n/m 已启用)→ 启用中工作流快捷区 → 状态卡(扩展三态 + 监控文件夹数 + 重启 Finder)

**动作库页(新 ActionLibraryView)**:场景 chips 行(⭐全部 · 5 场景 · ✏️自定义)+ 搜索框 + **紧凑列表**(emoji 色块 + 名称 + 一句话描述 + 使用次数 + 开关,一屏 15+ 行)。选「自定义」chip 时工具栏出现 新建/导入/导出,行带编辑/删除;编辑器复用现有 ScriptEditorView 内嵌。无监控文件夹时顶部显示提示横幅(沿用现有逻辑)

**工作流**:画布机制、试运行、模板全部不动,仅重绘列表行/工具栏/节点卡为新主题

**扩展页**:保留独立页(近期刚建的),组件化重绘

**设置页**:分组重排(外观语言/右键菜单/监控文件夹/应用行为/关于),**删除与扩展页重复的扩展列表块**(设为一行状态 + 跳转按钮,功能不丢)

## 三、功能保全映射

| 现有功能 | 新位置 |
|---|---|
| 场景动作浏览/开关/使用频率 | 动作库 chips+列表(行内次数) |
| 最近使用 | 首页「常用」区 |
| 自定义动作 CRUD/试运行 | 动作库·自定义 chip |
| 导入导出 | 自定义工具栏 + 文件菜单(**补接线**,现通知无监听) |
| 用户自建分组 | **补接线** CategoryEditorView(代码已存在但无入口,右键菜单分组逻辑本就支持) |
| 扩展管理/重启 Finder | 独立扩展页 |
| 监控文件夹/右键菜单开关/语言/外观/登录自启/通知 | 设置页各分组 |
| 菜单栏/Dock/结果窗/右键菜单本身 | 不动(右键菜单是产品核心,本次不改) |

## 四、一致性清理(顺手做)

- ScriptEditorView/ImportExportView 硬编码英文全量改 `L10n.text`(AGENTS 约定)
- 统一强调色、统一场景色源、修 `organize` emoji 不一致(📥/📦 两处)
- 双语刷新机制(`languageEpoch + .id()`)全站沿用

## 五、实施与验证

实施分为四个阶段，每阶段运行 `./scripts/build-app.sh release` 验证构建。

1. 主题基建 + 窗口壳 + 首页
2. 动作库页(含自定义动作/编辑器/导入导出迁入)
3. 工作流/扩展/设置重绘
4. 一致性清理 + 接线 + 收尾

每阶段启动 App 后 `screencapture` 截取主窗口,明暗两种外观下自查对比度与布局;全部页面过一遍功能开关冒烟(动作开关、工作流保存、导入导出、扩展状态)。
