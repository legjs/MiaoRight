# 日常功能补齐

目标由用户于 2026-11-19 确认。按以下顺序实施，全部使用离屏界面与隔离数据验证。

1. 常用目录与固定复制、移动目的地。
2. 从用户提供的文件模板新建副本。
3. 统一解压入口、更多格式、常见分卷和加密压缩。
4. 剪贴板条目收藏与常用片段。
5. 可预览、检查冲突的批量重命名。
6. 生成结果定位，以及移动、重命名的安全撤销。

约束：保持现有三页导航与默认菜单，附加能力按需配置；双语、原生设置行、内嵌详情；保留用户旧配置。测试不启动 App/Finder、不激活窗口、不模拟键盘鼠标、不写系统剪贴板，不触达用户的 App Group、默认偏好或正在运行的 App。

本次隔离根目录：`/tmp/MiaoRight-FeatureGoal-rh7aje26`。构建设置 `MIAORIGHT_APP_OUTPUT` 和 `MIAORIGHT_SWIFT_BUILD_PATH`；测试显式设置 `MIAORIGHT_OFFSCREEN_TESTING=1`、`MIAORIGHT_TEST_STORAGE` 与 `MIAORIGHT_CLIPBOARD_TEST_STORAGE`。隔离测试不会发送 Finder 刷新通知或启动剪贴板采集。

## 已实现

| 能力 | 用户入口与行为 |
|---|---|
| 常用目录 | 右键菜单页默认折叠的“常用文件夹”；每个目录分别启用打开、复制到、移动到，移动执行前确认。失效路径提示修复。 |
| 文件模板 | 同页“文件模板”，从现成文件或文档包保存快照；在目标文件夹右键新建副本，同名自动递增，原件不变。移除菜单引用保留快照，以兼容旧引用。 |
| 压缩与解压 | 按需添加“压缩…”和“解压”；压缩表单支持 ZIP / 7Z / TAR.GZ，前两种可设密码。解压识别 ZIP、7Z、RAR、TAR、GZ、BZ2、XZ 及 TAR 包装、常见分卷，独立目录输出、不覆盖。密码只经 stdin，不保存。 |
| 收藏与常用文字 | 记录菜单切换收藏，侧边栏“全部 / 收藏”；设置中保存常用文字。旧 SQLite/JSON 自动补默认收藏状态；收藏不随普通历史到期、条数或清理而删除。 |
| 批量重命名 | 按需添加“批量重命名…”；预览替换、前后缀、编号、大小写与空格转换，保留文件扩展名；冲突、无效名字或预览后来源变化时阻止执行。 |
| 位置与撤销 | 内嵌结果及菜单栏提供结果定位、移动/重命名撤销；保留本次会话最近 20 批。批次预检查、两阶段重定位、失败尝试回滚，目标变化或原位置被占用时拒绝撤销。部分剪切成功仍保留未完成清单并可撤销已完成部分。 |

既有配置与默认菜单保留；三页胶囊和四个核心设置行不变。常用目录使用带专用标记的原组合动作 JSON，不把无标记旧配置改造成新功能。压缩与重命名表单内嵌主窗口，执行中禁用重复操作和切页。

## 边界

撤销仅在当前 App 会话中有效，记录基于文件身份、大小、修改日期、权限及目录子项等元数据检查，不宣称能识别刻意保留元数据的内容篡改。不会通过覆盖/删除冲突文件强行撤销；极端回滚失败会报告保留的恢复路径。

分卷应位于同一目录，已测试实际 ZIP/7Z 数字分卷和真实普通 RAR；RAR 分卷命名识别有回归，未穷尽全部第三方分卷变体。ZIP 加密密码限定 ASCII，含中文请使用 7Z；TAR.GZ 不提供加密。

本轮未进行新增菜单的 Finder 前台点击、真实输入法、VoiceOver、物理三屏、权限弹窗或完整端到端验收，以遵守不影响用户使用的要求。构建仍有既存 Swift 并发/弃用等警告，构建通过不等于完整套件与上述前台检查通过。
