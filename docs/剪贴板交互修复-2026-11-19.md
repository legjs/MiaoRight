# 剪贴板交互修复

本文记录 2026-11-19 的交互修复。图片文字搜索、剪贴板记录保存和倒数第二条快捷粘贴的用法见[当前剪贴板说明](../README.zh-CN.md#剪贴板历史)。

本轮对应用户反馈的四项问题：当前选中状态不明显、序号样式、确认后未填入目标输入框、展开时应默认第一条。

- 当前行增加蓝色描边、左侧标记与“已选中”文字；浅/深色焦点底色分别为 0.14 / 0.26，增加对比度时描边为实色。多选复选框仍独立工作。
- 前十项的 1–9 / 0 数字快捷键改为 22×20 点键帽，移出时间信息，保持数字快选。
- 自动粘贴由面板统一调度，单选、数字、点击与合并多选共用确认路径。先写剪贴板，再等待收起完成；固定模式以非 key 方式保留面板。随后恢复呼出前的目标应用，等待键盘焦点释放和目标连续就绪，再向目标进程发送 ⌘V。取消固定后既有自动收起行为保留。
- 粘贴前检查辅助功能权限、目标存活/激活状态及剪贴板版本；用户切换到第三个应用、复制新内容或重新打开面板时取消待发送粘贴。未授权时保留复制能力并显示授权入口。直接粘贴默认开启，已有明确关闭的设置保留；本机检查时用户设置原已开启，因此该次故障修复重点是交还焦点的时序。
- 每次展开时清空上次多选并定位第一条可见记录，滚动到顶部；保留搜索和筛选条件。输入法组词仍优先接收回车、空格和方向键。
