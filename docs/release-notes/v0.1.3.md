## 中文

### 新增

- 妙右现已按 MIT License 开源发布。
- 公开的 GitHub Releases 支持无需 GitHub 登录的一键检查更新和原位安装。
- 新增三步安装引导和 App 内首次使用检查清单。

### 变更

- 下载 ZIP 或选择已有 ZIP 后，妙右会校验版本、架构、嵌套扩展和发布证书，再替换 `/Applications/MiaoRight.app` 并重新启动。
- 发布流水线在单个 Apple 芯片 runner 上原生构建 arm64，并交叉构建 x86_64。
- MIT 版权信息现包含 MiaoRight contributors。

### 修复

- 修复深色模式下更新说明文字不可读的问题。
- 改进 Finder 扩展状态反馈，并移除重复创建设置窗口的问题。

### 安全

- 更新包必须由稳定的 MiaoRight Release 身份签名，且主程序和所有嵌套扩展必须通过固定证书指纹校验。

## English

### Added

- MiaoRight is now distributed as an open-source project under the MIT License.
- Public GitHub Releases support one-click update checks and in-place installation without GitHub authentication.
- Added a three-step installation guide and an in-app first-run checklist.

### Changed

- After downloading or selecting a ZIP, MiaoRight validates the version, architecture, nested extensions, and release certificate before replacing `/Applications/MiaoRight.app` and relaunching.
- The release pipeline builds arm64 natively and cross-compiles x86_64 on one Apple silicon runner.
- MIT copyright information now includes MiaoRight contributors.

### Fixed

- Fixed unreadable release-note text in dark mode.
- Improved Finder extension status feedback and removed duplicate settings-window creation.

### Security

- Updates require the stable MiaoRight Release identity and fixed certificate fingerprints for the app and every nested extension.
