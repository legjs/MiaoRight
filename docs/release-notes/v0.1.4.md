## 中文

### 新增

- 菜单栏图标菜单实时显示更新状态：检查中、已最新、检查失败和发现新版本。
- 发现新版本时可在菜单栏直接安装，并提供独立的更新日志入口。

### 变更

- 手动检查更新会弹出独立对话框，显示更新日志和更新按钮；没有新版本时提示已是最新版本。
- 应用启动不再自动打开设置窗口；设置页仅在从菜单栏或 Dock 打开时显示。
- 菜单栏更新操作直接打开更新弹窗，更新日志只在弹窗中显示。

### 移除

- 移除手动选择 ZIP 的更新方式，更新统一下载与当前架构匹配的发布包。
- 移除开发版更新模拟调试开关。

## English

### Added

- The menu bar icon menu now shows a live update status for checking, up-to-date, failure, and available-update states.
- An available release can be installed directly from the menu bar, with a separate release-notes shortcut.

### Changed

- Manual update checks open a dedicated dialog with release notes and an update button; checks with no update show an up-to-date alert.
- The app launches silently without opening the settings window; the settings window appears only when opened from the menu bar or Dock.
- The menu bar update action opens the update dialog directly, and release notes appear only in the dialog.

### Removed

- Removed manual ZIP selection from updates; updates always download the asset matching the current architecture.
- Removed the development-only update simulation switch.
