## 中文

### 新增

- 新增 Apple 芯片与 Intel 芯片的 DMG 安装包，包含“应用程序”快捷方式和安装说明。
- 新增三步安装引导，并在妙右「通用」页提供首次使用检查清单。

### 变更

- 生产版本支持在 `/Applications/MiaoRight.app` 原位更新。
- 更新包会校验版本、架构、嵌套扩展和发布证书；安装失败时保留旧版本。
- Finder 扩展检查现在会明确显示已就绪、等待加载和未启用三种状态。
- 首次从开发签名版本切换到生产签名版本时，需要重新确认系统权限和登录项。

### 修复

- 修复设置入口可能打开两个设置窗口的问题。
- 修正 macOS 26 从构建目录启动时 Finder 扩展可能不加载的本地测试流程。

## English

### Added

- Added DMG installers for Apple silicon and Intel Macs, including an Applications shortcut and installation instructions.
- Added a three-step installation guide and a first-run checklist in General settings.

### Changed

- Production builds can now update `/Applications/MiaoRight.app` in place.
- Updates validate the version, architecture, nested extensions, and release certificate, and retain the previous app if installation fails.
- Finder extension checks now clearly report ready, waiting to load, and disabled states.
- The first switch from a development-signed build to a production-signed build requires confirming system permissions and the login item again.

### Fixed

- Fixed the settings action potentially opening duplicate settings windows.
- Corrected the local macOS 26 workflow for Finder extensions that do not load when launched from a build directory.
