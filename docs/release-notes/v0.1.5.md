## 中文

### 新增

- 更新弹窗实时显示下载进度，包括百分比和进度条，菜单栏状态同步显示。
- 更新弹窗可将更新日志在中文和英文之间切换。

### 变更

- 下载未完成时点击「稍后」会取消下载，不再后台继续。
- 更新包就绪后关闭弹窗会说明更新将继续，妙右安装完成后自动重启。

## English

### Added

- The update dialog shows live download progress with a percentage and a progress bar, mirrored in the menu bar item.
- The update dialog can switch release notes between Chinese and English.

### Changed

- Later cancels an ongoing update download instead of continuing in the background.
- Once the update package is ready, closing the dialog explains the update continues and MiaoRight relaunches automatically.
