## 中文

### 新增

- 更新弹窗新增「跳过此版本」，软件更新设置中可取消跳过，新版本发布后会重新提示。
- 更新下载失败时自动重试，最多三次。

### 变更

- 下载失败提示改为说明网络原因，并建议从发行页面手动下载 DMG。

## English

### Added

- Added Skip This Version to the update dialog, with a Stop Skipping control in the update preferences; newer releases prompt again automatically.
- Update downloads now retry up to three times before reporting a failure.

### Changed

- The download failure message now explains the network cause and points to the DMG on the release page.
