# 已确认方向：轻量原生工具

模式：Operate。平台：原生 macOS SwiftUI / AppKit。

视觉依据：用户确认的轻量设置方向及后续顶部胶囊、三种外观、原生毛玻璃修正。当前设计真值是 DESIGN.md 与 .impeccable/design.json；早期侧栏预览仅为历史参考。

首屏：64 点顶部栏，居中的“右键菜单 / 剪贴板 / 通用”胶囊导航，无侧栏、无顶部品牌字，右侧保留扩展连接状态。右键页四个核心设置行，其他已添加功能默认折叠。36 点程序图标、名称与版本位于通用页底部。

布局：默认 780 × 600、最小 680 × 540 点；页面内边距 28 点，设置行垂直 16 点，行内间距 12 点。系统 13 点正文、12 点说明、22 点页面标题。胶囊导航使用 12 点文字，选中表面轻微阴影。

外观：跟随系统 / 浅色 / 深色三选并持久化。主窗将 underWindowBackground / behindWindow / active 材质放在 NSHostingView 下方的原生兄弟视图中；剪贴板在滑动容器内使用同一材质。模糊层 alpha 保持 1，浅色白色 0.60、深色黑色 0.50 的独立原生底色调节厚实度，不能把图层 alpha 等同于背景实际透出百分比。系统辅助功能要求减少透明度或提高对比度时回退实色。

图标：界面使用 SF Symbols，本机应用使用 NSWorkspace 真实图标。妙右程序与 Finder 扩展使用蓝底白色菜单+光标的原创矢量图标；Packaging/Icons/GenerateIcons.swift 与 scripts/generate-icons.sh 自动导出 PNG、十项 iconset、ICNS 和菜单栏模板，构建时重生成。程序图标的渐变仅属于图标资产。

签名交互：Finder 菜单固定顺序；320 点剪贴板面板在目标屏幕固定窗口内裁剪滑入。搜索时输入法拥有按键，列表定位和多选分离。胶囊选择 spring response 0.25 / damping 1；Reduce Motion 关闭动画。

保留边界：不恢复磁贴墙、功能数量指标或编排主入口；保留已有用户配置、81 项附加功能目录、双语与原生执行机制。

验证：最终 release 组装、深度签名检查通过。此前同源原生 fixture 覆盖三种外观及 native sidebar / active / alpha 0.90，四张截图位于 .impeccable/review/glass。实机已确认三种外观切换、收敛后的深色材质和扩展连接，随后恢复用户的跟随系统设置。通用底部信息通过 880 点高 fixture 截图核对；未宣称实机滚动、VoiceOver、物理三屏、权限或减少透明度全链路通过。
